# 🎰 Online Party Poker

เกมไพ่ปาร์ตี้ออนไลน์สำหรับเล่นกับเพื่อนๆ แบบ real-time!

## ✨ Features

- 🎮 **Multiplayer Real-time** - เล่นกับเพื่อนได้จริงผ่าน Firebase
- 🚪 **Room System** - สร้างห้องและแชร์รหัส 6 หลัก
- 🃏 **52-Card Deck** - ไพ่ 4 ชนิด ♥ ♦ ♣ ♠
- 🎯 **Party Challenges** - Truth/Dare/Drink ตามไพ่ที่จั่ว
- 📱 **Responsive** - เล่นได้บนทุกอุปกรณ์
- 🎨 **Beautiful UI** - ธีม Casino สวยงาม

## 🚀 วิธีตั้งค่า Firebase

1. ไปที่ https://console.firebase.google.com/
2. สร้าง Project ใหม่
3. เพิ่ม Web App
4. คัดลอก Firebase Config แล้วใส่ในไฟล์ app.js
5. เปิด Firestore Database (test mode)
6. Deploy!

## 🎮 วิธีเล่น

1. **สร้างห้อง** - รับรหัสห้อง 6 หลัก
2. **แชร์รหัส** - ให้เพื่อนๆ
3. **จั่วไพ่** - ทำตามคำสั่ง
4. **สนุก!** 🎉
