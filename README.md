# 🎉 เกมปาร์ตี้วงเหล้า

เว็บเกมปาร์ตี้สุดสนุกสำหรับวงเหล้า! เล่นได้บน iPad หรืออุปกรณ์ใดก็ได้

## 🎮 เกมทั้งหมด

### 🏴‍☠️ เกมโจรสลัด
- เสียบดาบเข้าถังทีละอัน
- ระวัง! อาจทำให้โจรสลัดโผล่ขึ้นมา
- ถ้าโจรสลัดโผล่ = ดื่ม! 🍺

### 🐊 เกมจระเข้
- กดฟันจระเข้ทีละอัน
- ระวังอย่าให้ปากกัด!
- ถ้าปากกัด = ดื่ม! 🍺

### 🎴 ไพ่ปาร์ตี้
- จั่วไพ่และทำตามที่ไพ่บอก
- มี 4 ประเภท:
  - 💭 **TRUTH** - ตอบคำถามตามตรง
  - 🔥 **DARE** - กล้าทำกล้ารับ
  - 🍺 **DRINK** - ดื่มตามที่กำหนด
  - 🎮 **MINI GAME** - เล่นเกมย่อย

## 🚀 วิธีเล่น

### เปิดบน iPad
1. เปิดไฟล์ `index.html` ด้วย Safari หรือ Chrome
2. เลือกเกมที่อยากเล่น
3. สนุกกับเพื่อนๆ!

### เล่นออนไลน์
หากต้องการให้เพื่อนๆ เข้าเล่นผ่านเน็ต สามารถใช้:
- GitHub Pages
- Netlify
- Vercel

เพียงแค่ upload ไฟล์ทั้งหมดขึ้นไป!
